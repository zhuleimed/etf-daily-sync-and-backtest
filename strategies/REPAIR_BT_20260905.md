# 修复性回测归档：动量类模拟盘 8 月择时摩擦修复研究（2026-09-05）

## 一句话结论
2026 年 8 月模拟盘 momentum/macd 集体亏损，**不是市场普跌**（沪深300 持平 +0.11%、中证1000 反 +6%），而是动量类在 **2026-08-19 单日小盘假恐慌** 上的两处择时摩擦；而 **momentum 的额外 -1.9pp 实为 08-18 "同一交易日被重复重跑"制造伪切换**（非平滑问题）。只有 **macd 用 `confirm_days=2`** 是唯一非负优化候选，已促销真盘。

|---|---|---|---|---|

08-19 是被资金避险砸出的一日脉冲、次日便回补。momentum/macd 恰在 08-18 旋转进小盘，吃这段。

## 触发调查：momentum 为何 -3.76 而不是干净的 -1.87
干净单日重放（真实引擎、一次/天）跑 seed=08-03→09-04：
- **momentum_rotation**: 完整复现 live 直到 **2026-08-17 逐日精确(≤0.004元)**；
  08-18 之后 live 转持 512100、clean 仍持 563000，focal -1.87 vs live -3.76。
  → momentum `sim_log` 在 **2026-08-18 有 4 行同一日**（含一笔当日切换）。

### 调度根因（已定位）
pipeline 对 `momentum_rotation` 恰好调用**一次**（`STEPS` 仅 1 个 id 指向其 daily；`for step` 无重试）。
08-18 主管道（pipeline_20260818.log）在 **ETF 数据同步阶段即 fail**（腾讯源连续抽风切换 Sina/回切，见 retry 同步日志 20:44 段），
随后 pipeline_20260818_retry.log 于 20:44 重跑一次且仅 run momentum 一次。→ 仅管道无法解释 sim_log 4 行。
**4 行说明 momentum 在 08-18 被 4 次独立执行**（第1次失败后 1 次 retry + 用户在当日多次手工重跑/排障/核数据，
叠加同日晚腾讯源不稳）。而**模拟盘层没有任何"同一交易日最多处理一次"的幂等**：
engine 每次 `run_daily` 都 `days_since_switch += 1` 并 append 一行 —— 反复执行会在状态上推进足够天数，
最终触发一笔"单次执行本不会发生"的 563000→512100 当日切换，吃掉约 -1.9pp。
这才是 momentum live(-3.76) 与 clean(-1.87) 之差的根：**不是择时摩擦，是"同日多次执行"的累积推进**。
修复(commit bed710d)：两模拟盘 daily `main()` 已加幂等护栏——`state.last_update==today_str` 则跳过，
已跑护为功能测试通过（同日第2次 skip、新交易日放行、新账号放行）。
- **macd_trend_rotation**: 干净单日完全复现 live **-7.58%**（risk B 真清仓→08-20 转现金→踏空→09-01 追高回补，真实摩擦）。
  macd 仅 08-18 有 2 行(次要)，主体亏损为真实 risk 模式所致；confirm2 促销已拦截该类 churn。

## 可复用排查套路(此后"某策略某月为何亏/是否分层"直接套用)
1. 先摆基准别先归因:只看**同期大盘涨跌**(本段沪深300 +0.11%、中证1000 +6%)——平/涨月策略还亏多是内部摩擦而非市场。
2. 看 sim_log 是否有**同一交易日多行**(同日被重复重跑)→ 有先当 artifact 排查(幂等护栏 bed710d 已拦未来)。
3. 引擎可复现性: repair_bt.py clean 单日重放 → 与 live 逐日比对(≠0.5元即为分叉点)。
   分叉=live 异于"引擎一次/天"的点,是 bug 或对手动重跑交互,别马上当策略问题。
4. 在 clean 引擎上跑杠杆矩阵(当期 + 全窗两轴)判"非负优化",别 only 当期(防单日 overfit)。
5. **不要把"clean重放末仓"当"该持 oracle"**:带切换阈值/粘性策略查它当下 #1,路径依赖下 clean 停的仓≠信号支持
   (本段 momentum live 持 512100 即真实 #1;回拨 563000=逆信号)。
6. 想动实盘/历史仓位前:真bug/artifact/sunk 分类 × 现值差 × 验当下信号,三者缺一不动(见记忆
   clarify-before-position-mutation / sticky-strategy-path-dependence)。

## 事后裁量：momentum 假切换仓位【不回拨】(2026-09-05)
虽 momentum live(-3.76) 较 clean(-1.87) 差约 -189元(-1.9pp)，但**不**把 512100 拉回 563000：
- momentum 自 08-18 起一直持 512100，#1 真实信号自 08-24→09-03 亦正是 512100；
  momentum 为"粘性"策略(需 target 动量超 current≥3% 才 rotate)，clean 停在 563000 是"没换"而非"应持"。
- ⇒ 回拨到 563000 = 为对齐历史账目而做的无信号投机，会逆自身动量；那 -1.9pp 是 08-18 提前买高的 sunk cost。
- 幂等护栏挡未来同日重复即够；历史假切换仓照常持有。
- 教训："对齐历史轨迹" vs "对齐未来信号" 须区分；粘性策略路径依赖，clean 一条路径 ≠ 正确未来方向。

## 局限性（诚实记录）
- clean 单日引擎 ＝ live 引擎一次/天的理想；若 live 某日在同日确实需要因 DB 回补而重跑，幂等护栏会跳过该日(可能丢一天 CSV)。
- macd 促销为**单一参数经验确认**，样本为一次月度事件+全窗；建议真盘再观察数周/月在确认。
- 事件是单点 08-19，属小样本；结论依赖"不因单一事件 overfit"的全窗交叉验证。

## 附：跨全部策略审计归类(2026-09-05)
全 20 策略 sim_log: 最差单日几乎全是 **2026-08-19**(全市场中/小盘单日 -3~-6% 脉冲)。逐类：
- **滞后轮动单标的β盘(≈-2%)**: median/sharpe/sortino/bollinger/spread/tail/volume_price/momentum_vol_filter/dual_momentum
  终持多为 512100,大多 ~08-20/08-24 才轮入(已涨完的动量榜最强),吃 08-19 单日 -2.8% 末端回吐→ seg≈-1.9~-2.1。
  ⇒ **动量固有"追已涨完最强→吃回吐"成本,非框架bug**(clean 引擎照旧)。
- **切换+风控双摩擦盘(最差≤-5%)**: composite/cross_border/macd: 有 sw>0 且 risk>0(风控清仓/转现金→踏空→再买高),累及 08-19 + 二次进出 → -5~-9%。
- **artifact 影响**: 08-18 当夜几乎全部盘同日多行(重复重跑,pipeline 20:00 fail→20:44 retry + 手动),仅 momentum 因此被推进触发一笔伪切换(-~1.9pp,已由幂等护栏拦)。
- **幸存正收益**: neural +1.42 / gold_safe_haven +1.22 / asset_allocation +0.50 —— 非"追最强单个动量名"者(防御/分散/年内均配),躲过动量共同暴露。

**总因一句话**: 主要非 bug、非框架错,而是 - ①动量体系"滞后追已涨完单名→吃回吐"(clean也-2%) + ②8月中途 08-19 全市场单日恐慌放大 + ③8-03 清零起点恰逢市场见顶(起点效应)。可修面有限已验证: 幂等护栏(artifact) + macd confirm2(risk-B二次摩擦)为唯二非负优化项。
